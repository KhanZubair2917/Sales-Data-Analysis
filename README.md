# Sales Data Analytics

This project analyzes sales data to identify revenue trends and support business decisions.

## Dataset

Started with 305 rows, cleaned down to 297 rows after removing duplicates and outliers. Includes order details like product, category, region, price, and units sold — 7 columns total. Contains realistic data quality issues (duplicates, missing values, outliers).

## What I Did

- Cleaned the data: handled missing values, removed duplicates, standardized text
- Analyzed revenue by category, region, and product
- Visualized findings for better understanding

## Key Findings

We're making the most out of Electronics, with the North region leading in sales. Laptop is our most revenue-generating product. We're missing region data for 15 orders, which isn't ideal — I'd recommend investigating the data collection process to prevent future gaps.

## Tools Used

Python, pandas, matplotlib
